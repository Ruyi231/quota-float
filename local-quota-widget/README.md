# Codex 本地额度 v1.3.5

一个仅在本机运行的 Windows 浮窗，用来显示 Codex 会话日志里最近一次记录的额度状态。

## 功能

- 圆形收起、悬停展开、拖动和置顶；收起后保持刚刚拖动的位置，并可跨启动保存
- 深海、极光、暖白、樱粉四套内置皮肤，也可选择自己的照片换肤
- 照片仅保存在软件自己的本地数据目录中，导入时会验证、缩放并去除原始元数据
- 不显示任务栏图标；关闭按钮只隐藏到系统托盘，托盘可恢复或彻底退出
- 浮窗主显示 5 小时额度剩余；展开后保留 5 小时和周额度及各自重置时间
- 显示重置卡次数与到期时间
- 打开软件即确认在线额度查询；默认每 1 分钟自动在线刷新，并可在浮窗中调整间隔
- 手动刷新后只接受时间更新的后续记录，后台本地刷新不会把显示回退到旧数据
- 额度刷新不再重复请求重置卡专用接口；专用查询具有冷却和 429 重试提示
- 在线额度接口临时失败但本地日志已有刚写入的新额度时，按成功刷新显示，并对 429 进入冷却

## 隐私边界

- 启动、定时刷新和展开刷新会读取 `~/.codex/auth.json`，并访问 ChatGPT 额度接口
- 刷新间隔默认为 1 分钟，可在展开面板中改为 2、5、10 或 30 分钟
- 额度接口返回 429 时，软件至少 5 分钟只读取 `~/.codex/sessions/**/rollout-*.jsonl`，避免继续触发限流

本地日志不包含重置卡字段，重置卡刚使用后也可能尚未写入新的额度事件。
启动软件即视为允许定时在线查询额度：软件会读取 Codex 登录凭据，并访问
ChatGPT 的 `usage` 额度接口。该操作不会发送对话、不会兑换重置卡，也不会调用模型。
在线额度服务临时失败或返回 429 时会回退到本地日志。重置卡仍仅在用户点击
“在线查询”后才会访问 `rate-limit-reset-credits` 接口。

界面由系统 WebView2 渲染，运行时可能使用本机回环连接作为内部通信。
照片选择器和图片校验由本地 Rust 后端处理；前端不能指定任意文件路径。
照片不会上传，也不会触发网络请求。

## 构建

```powershell
cd src-tauri
cargo test
cargo build --release
```

生成的便携版程序位于 `src-tauri/target/release/local-quota-widget.exe`。
